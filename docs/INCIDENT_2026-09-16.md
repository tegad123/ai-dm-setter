## ManyChat callback contract

Every endpoint accepts the account-specific secret through the
`X-QualifyDMs-Key` header. Do not put that value in this document.

### Initial context or button-response handoff

`POST https://qualifydms.io/api/webhooks/manychat-handoff`

Required for Instagram:

- `platform`: `instagram` or omitted, since Instagram is the default
- `instagramUserId`: contact identity exposed by the flow; Convlo resolves the
  actual Instagram numeric ID through the ManyChat subscriber API when needed
- `instagramUsername`
- `manyChatSubscriberId`
- `openerMessage`
- `triggerType`: `new_follower`, `comment`, `story_reply`, `post_dm`, or `other`

Optional:

- `leadResponseText`: the lead's button response or first answer
- `nativeQuestion`: the question ManyChat asked
- `commentText`
- `postUrl`
- `firedAt`: ISO-8601 timestamp
- `scheduleAi`: boolean, normally `false` while the ManyChat flow continues

Example shape:

```json
{
  "platform": "instagram",
  "instagramUserId": "<contact id>",
  "instagramUsername": "<ig username>",
  "manyChatSubscriberId": "<manychat subscriber id>",
  "openerMessage": "<message ManyChat sent>",
  "nativeQuestion": "<question ManyChat asked>",
  "leadResponseText": "<lead answer or button label>",
  "triggerType": "comment",
  "commentText": "<source comment>",
  "postUrl": "<source post URL>",
  "firedAt": "<ISO-8601 timestamp>",
  "scheduleAi": false
}
```

### Capture each ManyChat outbound message

`POST https://qualifydms.io/api/webhooks/manychat-message`

Required: `instagramUserId`, `messageText`.

Optional: `instagramUsername`, `manyChatSubscriberId`, `sentAt`, and
`manyChatMessageId`. Supplying `manyChatMessageId` gives deterministic retry
deduplication.

### Final control-transfer signal

`POST https://qualifydms.io/api/webhooks/manychat-complete`

Required: `instagramUserId`.

Optional: `instagramUsername`, `manyChatSubscriberId`.

This endpoint marks the existing conversation ready for Convlo processing. It
does not itself change Meta's app-level thread ownership. Meta Conversation
Routing must separately permit Setter-IG to own or take control of the thread.
